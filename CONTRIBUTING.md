# Contributing

Project owner: **Jussi Alanen** ([GitHub: jussipalanen](https://github.com/jussipalanen)).

For changes, open an issue and use a dedicated branch such as `feat/document-library`. Create a PR to `main` and ensure `verify` is green. A human must review and merge it; agents must not self-approve or merge. See [AGENTS.md](AGENTS.md) and [ROADMAP.md](ROADMAP.md).

Configure a `main` branch ruleset manually in GitHub: require pull requests, at least one approval and the `verify` status check. CODEOWNERS documents ownership but does **not** by itself enforce review.
